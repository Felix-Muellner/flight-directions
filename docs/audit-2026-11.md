## Findings

### Security

| ID | Finding | Severity |
|---|---|---|
| S1 | `index.html` loads Google Fonts from Google's servers, so every visitor's IP address is sent to Google. A German court (LG München, 2022) ruled this a GDPR violation for a publicly hosted site. | Medium (privacy) |
| S2 | GitHub Actions in `ci.yml` and `deploy.yml` are pinned by version tag, not by commit SHA. The deploy job has `pages: write` and `id-token: write`. | Low |
| S3 | The deploy workflow does not run `npm audit`; CI does. | Low |
| S4 | `npm run dev` listens on all network interfaces (`--host=0.0.0.0`), as the dev container needs. | Info |

Already fine: airport names render as plain text (no XSS path); airport
database entries are validated one by one; the coordinate patterns guard
against catastrophic backtracking; the gitleaks download is checked against
a pinned SHA-256; CI permissions are `contents: read`.

### Redundancy

| ID | Finding | Where |
|---|---|---|
| R1 | The magnetic model cache is keyed by the exact millisecond and never hits in the app; building the model takes about 0.06 ms. | `src/route.ts` |
| R2 | `parseCoordinates` is used only by tests. | `src/coordinates.ts` |
| R3 | The airport code pattern in `location.ts` repeats the ICAO and IATA patterns in `airportDatabase.ts`. | `src/location.ts` |
| R4 | Colours `#1E293B` and `#07090E` are repeated 8 times. | `src/App.tsx` |
| R5 | `INPUT_BORDER.warning` is identical to `INPUT_BORDER.neutral`. | `src/App.tsx` |

### Complexity

Low overall; the largest function, `calculateRoute`, is about 40 lines.

| ID | Finding |
|---|---|
| C1 | Nested ternaries choose the route notice (`route.ts`) and the input style (`App.tsx`). |
| C2 | `App` tracks the airport database in two state variables, which allows impossible combinations and adds a boolean parameter to `resolveLocation`. |

### File structure

A flat `src/` with one test file next to each module suits the project size.

| ID | Finding |
|---|---|
| F1 | `deploy.test.ts` and `bundledSnapshot.test.ts` test build and deploy setup, not app code. Cosmetic. |
| F2 | Only `App.tsx` has an `@license` header. |
| F3 | Stale, gitignored copies on disk (an old agent worktree, `dist/`). No effect on the repo. |

### Architecture

Sound: input parsing (`coordinates`, `location`), calculation and
formatting (`route`) and the React layer (`App`) are separate, and the app
takes its airport database loader and clock as parameters, which keeps it
testable.

| ID | Finding |
|---|---|
| A1 | The bundled snapshot is 8.7 MB (1.3 MB gzipped) and is fetched in full on every visit. Trimming it would conflict with its definition as stored unchanged. |
| A2 | `route.ts` mixes calculation and display formatting; fine at its current size. |

### Dependencies

Patch updates are available for biome, tailwind, vite and plugin-react.
Major versions are available for `lucide-react` (1.x), `vitest` (5) and
`jsdom` (31). `@types/node` should stay on 22 to match the Node version.
